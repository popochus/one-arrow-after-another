## 三、测试说明

- 全程无窗口运行：使用 SDL 的 dummy 视频驱动，不需要人工操作，可在命令行一次跑完。

- 通关类用例（T04、T07）的点击顺序由 `game/solver.py` 求解器现场算出，不是手工写死的步骤，因此关卡改动后测试仍然有效。
